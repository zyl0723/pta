规则（先看这里）

  • 完全公开：你发的每一条留言、每一条回复，任何人打开这个页面都能看到。
  • 不支持私聊：这里没有私信功能，所有交流都在这张页面上公开进行。
  • 永久保存、显示日期：留言保存在本仓库的 GitHub Discussions 里，会一直保留，并显示发布时间。
  • 谁能删：留言的本人可以删自己的留言；站长（仓库管理员）可以删任何一条。其他人删不了。
  • 需要 GitHub 账号：发留言要用 GitHub 账号登录（防机器人刷屏，也能确认「谁发的」）；不登录也能看全部留言。
  • 提问建议写清楚：题号 / 第几行 / 你想问什么；贴代码时最好把题目要求也贴上。
