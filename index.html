常见错误速查

  
下面这些是基础题里最常出现的问题，每一条都给出「错的写法」和「正确的写法」（例子都是 C 语言的写法；页面自带的检查规则也只针对 C）。点右侧检查结果里的条目会自动跳到对应行。

  


    

      
scanf 忘了 &

      
scanf("%d", n);

      
scanf("%d", &n);

      
scanf 要把读到的值写回变量，必须给地址。数组名本身是地址，scanf("%s", s) 不加 &。

    


    

      
double 用 %d 读入

      
double d; scanf("%d", &d);

      
double d; scanf("%lf", &d);

      
读 double 用 %lf，读 float 用 %f，读 int 用 %d。读错了数值完全不对。

    


    

      
printf 输出类型不对应

      
double d = 1.5; printf("%d", d);

      
double d = 1.5; printf("%.2f", d);

      
%d 只输出整数，输出浮点要用 %f（可写 %.2f 表示保留两位）。

    


    

      
整数除法丢了小数

      
int s = 7, n = 2; double a = s / n;

      
double a = (double)s / n;

      
两个整数相除结果只保留整数部分，7 / 2 得到 3 而不是 3.5。

    


    

      
少写分号

      
int a = 1
printf("%d", a);

      
int a = 1;
printf("%d", a);

      
一行语句结束要有分号。报错行号有时会指向下一行，要看上一行结尾。

    


    

      
条件里把 == 写成 =

      
if (a = 0) printf("零");

      
if (a == 0) printf("零");

      
= 是赋值，== 才是比较。写错后条件永远成立（或永远不成立）。

    


    

      
if 后面多了分号

      
if (a > 0);
    printf("正数");

      
if (a > 0) {
    printf("正数");
}

      
分号让 if 的语句体变成了空语句，后面的代码与判断无关，会无条件执行。

    


    

      
多组数据读不完 / 死循环

      
while (scanf("%d", &n)) { ... }

      
while (scanf("%d", &n) != EOF) { ... }

      
scanf 成功时返回读到的个数（大于 0），恒为真。读到文件结束要判断 EOF。

    


    

      
数组下标越界

      
int a[5]; a[5] = 1;

      
int a[5]; a[4] = 1;

      
int a[5] 的合法下标是 0 ~ 4。循环写 for (i = 0; i <= 5; i++) 也会越界。

    


    

      
用了中文标点

      
int a = 1；

      
int a = 1;

      
从 Word、PPT 复制代码会把英文标点自动换成全角，编译器会直接报错。

    


    

      
转义字符写成斜杠

      
printf("hello/n");

      
printf("hello\n");

      
换行是反斜杠 n，输出后会真的换行；/n 只会原样打印 /n。

    


    

      
long long 的占位符

      
long long s; printf("%d", s);

      
long long s; printf("%lld", s);

      
int 最大约 21 亿。求和、阶乘这类结果可能更大时，要用 long long 配 %lld。

    


    

      
字符串没结束符 / 数组太小

      
char s[5]; scanf("%s", s); // 输入 hello

      
char s[64]; scanf("%63s", s);

      
字符串末尾需要 '\0'，所以数组至少要能装下内容加 1 个字符，否则会写越界。

    


    

      
浮点数用 == 比较

      
if (a == 0.1 + 0.2) ...

      
if (fabs(a - 0.3) < 1e-6) ...

      
小数在计算机里无法精确表示，比较差值才可靠。

    


  


  

    
这个工具的边界

    
    
      
  • 静态检查只覆盖「常见写法错误」，它不会替你做算法判断。逻辑对不对，要靠运行样例来验证。
    • 
      
  • 运行使用的是一个内置的 C 解释器（JSCPP），覆盖基础题常用的语法和标准库函数，并已针对 scanf / printf / EOF / long long / int main(void) 这几种情况做了修正。
    • 
      
  • 遇到它不支持的写法时，会明确告诉你「无法运行」，不会随便给你一个结论。
    • 
      
  • 所有计算都在你的浏览器里完成，代码不会上传到任何服务器。
    • 
    

  






  本地运行 · 不上传代码 · 结果仅供参考，最终以 PTA 判题为准





  

    
    
这个页面能做什么


    
不接 AI 也能用。把代码粘到左边，点「立即检查」——它会指出错误在第几行、为什么错、怎么改；点「运行并对比」还会真的把代码跑一遍，和你填的期望输出逐行对比。这些都在你自己的浏览器里算，不联网、不花钱。


    
但它只检查你已经写好的代码。它自己不会解题、不会替你写代码、不会出题；你还没写出来的逻辑对不对，它也判断不了。它是一个检查工具，不是一个答题工具。


    
想让它更聪明，得你自己有 AI。不用登录、不用注册，点「生成答案与解析」或「生成相似练习题」，页面会按你的题目、你的代码和错误点拼好一段提问，然后二选一：填上你自己的 API 地址和密钥就能点「在本站生成」直接出结果；也可以点「复制提示词」，粘到你自己账号的 AI 网站（ChatGPT / DeepSeek / Kimi / 豆包 / 通义）去问。AI 会照着题目给出带注释的答案、帮你改错，还能照原题出相似的题让你练。本站不含 AI、不中转、也不替你付任何费用。


    
这个小工具是作者自己嫌反复拍照问 AI 太麻烦才做的，比较粗糙，能用就行。
