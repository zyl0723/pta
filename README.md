# C 语言习题检查器

> 作者：**zyl0723**（<https://github.com/zyl0723>）。本仓库自有代码版权归作者所有；用到的第三方组件（JSCPP 2.0.9、lodash 4.18.1、pegjs-util 1.4.21、printf 0.6.1、PEG.js 0.9.0、xterm.js 6.0.0、@xterm/addon-fit 0.11.0，均为 MIT）许可见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

一个纯前端网页工具，用来检查 PTA 平台上 C 语言基础题的代码。粘贴代码后，它会**直白地指出问题出在哪一行、为什么错、怎么改**，并且能**真的把代码跑起来**，把运行结果和题目要求的输出逐行对比。

> **在线使用（点开即用）：<https://zyl0723.github.io/pta/>** ｜ 源码仓库：<https://github.com/zyl0723/pta>

- 面向人群：初学 C 语言、在 PTA 上做题的学生。
- 设计底线：**准确优先于覆盖面**。只报有把握的问题，每条结论都同时给出「为什么」和「怎么改」；遇到无法确定的情况，明说无法确定，绝不编造结论误导学生。
- 隐私：所有计算都在浏览器本地完成，**代码不会上传到任何服务器**。

## 它能做什么

1. **静态检查**：边打字边分析，指出常见写法错误（下面有完整规则清单）。
2. **真实运行**：内置一个 C 语言解释器（JSCPP），可以直接运行你写的代码。
3. **逐行对比**：把程序输出和「题目要求的输出」逐行对比，标出第一处不同的位置。
4. **报错翻译**：把解释器的英文报错翻译成直白中文，并尽量给出出错行号和修改建议。
5. **样例实测**：内置常见基础题型的样例数据和参考实现，可一键填入、对拍。
6. **进站提示**：第一次打开时弹一个小窗，讲清这个页面能做什么、不能做什么（不接 AI 只能检查你已经写好的代码；想让它更聪明得用你自己账号的 AI）。勾选「不再提示」后就不再弹，这个记录只写在你自己的浏览器里（`localStorage`，键名 `pta-welcome-mute`），不上传。
7. **免登录使用**：不注册、不登录。「答案与解析」「练习」打开就能用，只把材料拼成一段提问，交给**你自己的** AI。
8. **自带 API Key**：填上自己的 API 地址、密钥和模型，就能直接在本站出答案、出练习题（也可以只复制提示词去自己的 AI 网站问）。密钥只在你自己的浏览器里，随时可一键清除。
9. **结果各归各的框**：生成的**答案 / 报错翻译**显示在右侧一个独立面板里，生成的**练习题**显示在左侧一个独立面板里，都带「复制」按钮，方便整段复制去别的网站。
10. **二次检查**：拿你生成的那份答案当标准，用你自己的 AI 把「你的代码」再对照着重查一遍，结果**覆盖**右侧「检查结果」；每改一次代码，点一下「二次检查」刷新。
11. **三段式答案 + 全屏**：「答案与解析」按「① 纯答案代码 / ② 代码 + 逐行注释 / ③ 容易出错的地方」分成三个框，背景**从淡粉到深粉逐段加深**，每段各有一个复制按钮；右上角「放大到全屏」可以把答案框铺满整屏，方便一行行对着看。
12. **网站使用提示**：「你的代码」面板右上角的「网站使用提示」按钮掌控各模块的说明文字——点一下把说明全部收起，界面只剩输入框和按钮，看着不眼花；再点一下显示回来。收起状态记在你自己浏览器里（`localStorage`，键名 `pta-hints-off`），下次打开保持上次的选择。
13. **像 Dev-C++ 一样：整屏写代码 → 检查 → 运行弹终端**：右上角「放大到全屏」之后，**整屏都留给代码**（说明文字自动收起，只有顶上一条工具栏和底下三个按钮），终端**不会**占代码的位置。流程是：

  - **检查**：点「立即检查」或终端窗口里的「检查」。有「错误」级问题时会**先别跑**，把「第几行、错在哪、怎么改」写清楚；全屏时右侧看不到「检查结果」，结果会自动打进弹出的终端窗口。
  - **运行**：把错误改掉后点「运行并对比」（或终端窗口里的「运行」）才会真的执行；万一遇到误报，再点一次「运行」＝强行运行，终端里会注明忽略了几个错误。
  - **弹终端**：一按运行就弹出一个独立的深色终端窗口（就像 Dev-C++ 运行程序时弹出来的那个控制台），里面直接显示程序输出；可以直接在里面打字：回车＝加一行输入、空着回车＝再跑一次、退格删字、Ctrl+C 清掉当前行。窗口可以拖动不了，但点「收起」或按 Esc 就关掉，代码区不受影响。
  - **互不影响**：终端窗口和「用样例数据实测」是两块独立的面板。终端有自己的输入缓冲，不会去改「程序输入」那个框；终端里没输入时，才会**只读地**用「程序输入」里填的样例数据跑。

  终端用的是开源库 [xterm.js](https://github.com/xtermjs/xterm.js) 6.0.0 加官方 [addon-fit](https://github.com/xtermjs/xterm.js/tree/master/addons/addon-fit) 0.11.0（均 MIT，已在 THIRD-PARTY-NOTICES.md 与 README 署名）。xterm.js 按需加载，首屏不会因此变大；没加载出来会自动退回页面自带的简易终端。
15. **顺手的小工具**：① 题目旁边的**「清空题目」**一键清掉题目框，接着粘下一题就行（只清题目，不动「应用修改」）；② 代码工具栏上的**「↶ 上一步 / 下一步 ↷」**是编辑器自己的撤销/重做（键盘 `Ctrl+Z` / `Ctrl+Y`、`Ctrl+Shift+Z` 同样可用），最多记 60 步，手滑删错、误点「清空」也能退回来。
16. **提问**（在「练习」和「API」之间）：看不懂哪一行就问哪一行。写清「第几行 + 你想问什么」→ 点「生成提问」，页面把**你的问题 + 题目 + 你的代码（带行号） + 语言 + 难度**拼成一段提问交给你自己的 AI。回答框里给出解释，规则是：**先给结论、再讲为什么、最后用一句大白话复述**；按难度选说话方式（简单＝尽量不用术语，困难＝可以用术语但要说人话）；能打比方就举一个生活里的例子；**不确定的地方必须明说「我不确定」，不许含糊、不许编**。和别的 AI 功能一样，需要你自己的 API（或复制提示词去你自己的 AI 网站）。
17. **留言板**（单独一个网址：`board.html`）：公开留言、互相答疑的地方。公开可见、永久保存、显示日期、**不支持私聊**；留言**本人**和**站长**可以删除，别人删不了。它用的是开源评论组件 [giscus](https://github.com/giscus/giscus)（MIT，已署名），留言存在本仓库的 GitHub Discussions 里，所以发留言需要 GitHub 账号登录（只看不用登录）。放在单独页面是为了**不影响主页面**：主页面不加载任何第三方脚本，CSP 保持严格；`board.html` 只额外放行 `giscus.app`。站长首次使用需要按页面上的 4 步说明配置一次（开启 Discussions、建分类、在 giscus.app 取两串 ID 填进 `assets/js/board.js`）。
14. **语言 + 难度（最高优先级）**：「你的代码」右上角有两个下拉框——**语言**（C 语言 / Python / C++ / Java）和**答案难度**（简单 / 中等 / 困难）。选完以后，页面里的答案与解析、练习、翻译、二次检查全都按这两个选择来：拼好的提示词里会写明「用哪种语言、给谁看的什么难度」。

- **难度**：`简单`＝只给新手能一眼看懂的写法（不用任何技巧）；`中等`＝简洁一些，允许用一点基础技巧（拆函数、常用库函数）；`困难`＝直接给最快最好用的写法（算法、标准库工具都用上，不照顾可读性、不绕弯子）。
- **语言**：`C 语言` 时本机的检查规则和解释器都能用（能静态检查、能真跑）；`Python / C++ / Java` 时本机没有对应的解释器和规则，页面的「立即检查 / 运行并对比」会**主动关掉并说明原因**，改由你自己配置的 AI 来检查（不会拿 C 的规则去误报）。
- 两个选择都记在你自己浏览器里（`localStorage`：`pta-code-lang` / `pta-answer-level`），下次打开保持上次的选择；「载入示例」会按当前语言给一份对应的入门代码。

## 怎么用

1. 打开网页（第一次会弹一个说明小窗，勾了「不再提示」以后就不弹了）。
2. 把你在 PTA 上写的代码粘贴到左侧「你的代码」框里。
3. 右侧会实时给出检查结果；点击某条结果会跳到对应代码行。
4. 想验证输出格式时：在「程序输入」里填题目给的样例输入，在「题目要求的输出」里填样例输出，点「运行并对比」。
5. 也可以从「用样例数据实测」下拉框里选一道题型，一键载入样例与参考实现。
6. 检查结果下面还有两个选填框：**题目**（把 PTA 上的习题描述整段粘进来）和**应用修改**（把 PTA 提交后给出的批改提示原文粘进来，比如「测试点 2　答案错误」）。它们不会上传，只是留在页面里当参考。

## 关于「题目」和「应用修改」两个框

这两个框是给你自己看的记录位，**不会自动上传**：内容只留在页面里，除非你自己点了「在本站生成」把它们发给你配置的 API。检查结果本身是浏览器里的规则匹配和内置 C 解释器算出来的，跟 AI 无关。

- **题目**：把 PTA 上的习题描述整段粘进来，方便你对着题意看检查结果和运行输出。
- **应用修改**：PTA 提交后给你的批改提示，它只说明**问题是什么**（答案错误 / 格式错误 / 段错误 / 运行超时 / 测试点未通过），不会说明原因和改法，原样抄进来就行。这块面板用灰粉色标出来，就是让你一眼看到「对着 PTA 反馈自查」的位置。
- 看不懂这些系统报错时，点这段下面的**「翻译成中文」**按钮：页面会把报错原文（连你的代码和题目一起）交给**你自己的 AI**，让 AI 用大白话告诉你到底哪里错了、该改哪一行。用法和「答案与解析」完全一样（在本站生成 / 复制提示词）。

## 没有账号系统，也没有服务器

**这个仓库是纯静态页面，没有后端、没有数据库，也没有登录/注册。** 早先的版本试过做「本机账号」（把账号存在浏览器本地），因为它给人「换台电脑也能登录」的错觉、又不能真的发验证码，后来**整个删掉了**：现在打开就能用，不再需要任何账号。如果你以前用过旧版本，页面启动时会顺手清掉残留的本机账号数据（`pta-accounts` / `pta-session` / `pta-pending-code`）。

页面不收集你的任何个人信息，也不上传你的代码：除非你自己点了「在本站生成」把它发给你自己配置的 API，否则所有内容都只留在浏览器里。

> 真要做「换台电脑也能登录、真的收验证码」的账号系统，必须部署一个后端（例如 Cloudflare Workers + KV，再用邮箱 SMTP 授权码发信）。那超出了这一个纯静态仓库的范围，也会引入服务器成本和隐私风险——所以现在的选择是：干脆不要账号。

## 接入你自己的 API，直接在本站出结果

页面右侧有一个独立的 **「API」模块**，填好下面几项并「保存并检测」，就能在本站直接拿答案和练习题，不用再跳去别的网站。模块最下面还放了一个蓝色小链接「获取api」，直接指向 DeepSeek 官网的 API Key 申请页（<https://platform.deepseek.com/api_keys>）。

| 要填的 | 说明 |
| --- | --- |
| 服务商 | 选一个预设（DeepSeek / OpenAI / 通义千问 / Kimi / 智谱 GLM），或选「自定义（OpenAI 兼容）」 |
| API 地址 | 选预设会自动填好，例如 `https://api.deepseek.com/v1`；自定义时按服务商文档填 |
| API Key | 在服务商后台申请，形如 `sk-...`。默认**不保存**；勾了「记住密钥」才会写进本机 `localStorage`（键名 `pta-ai-key`） |
| 模型 | 不知道填什么就点「拉取模型」，页面会调用 `GET /models` 列出可用模型 |

- 请求由**你的浏览器直接发往你自己填的这个地址**，用 OpenAI 兼容的 `POST /chat/completions`，流式返回并实时显示。本站不中转、不代理、不上传密钥、也不替你付任何费用。
- 只有在你点「在本站生成」之后才会发请求（也就是才开始算你自己账号的费用）；生成途中可以点「停止」。
- 如果服务商不允许网页直接调用（浏览器 CORS 限制），页面会明确说明原因，并提示改用下面的「复制提示词」方式。

## 「答案与解析」「练习」「翻译成中文」怎么工作

这三个按钮**不用登录、不用注册**，点开就能用。它们先把**你的题目 + 你的代码 + PTA 批改提示 + 自动检查出的错误点**拼成一段写得很详细的提问，然后你可以二选一：

- **在本站生成**：把这段提问发给你自己配置的 API（见上一节），结果显示在页面里。
- **复制提示词**：把提问复制到剪贴板，粘到你自己的 AI 网站（ChatGPT / DeepSeek / Kimi / 豆包 / 通义）去问。

无论哪种方式，**作答的都是你自己的 AI、花的都是你自己的额度**：本站不含模型、不中转、也看不到你的内容。点按钮只会拼好提示词并复制，不会再弹新窗口——要去哪个 AI 网站问，由你自己决定。

三个按钮分别要求 AI 做什么：

- **答案与解析**：要求 AI 给出**零基础也看得懂**的答案——只用最基础的写法（不写自定义函数、宏、指针技巧、位运算、递归），变量名用 a、b、n、i、sum 这种一看就懂的，能几行写完就几行写完，注释和易错点都用大白话说。AI 严格按三段给结果，页面把这三段分成三个框、背景**从淡粉到深粉逐段加深**：
  - **① 纯答案代码**：一份干净、能直接编译提交的代码，不带任何注释，右上角有「复制这段」。
  - **② 代码 + 逐行注释**：同一份代码，**注释单独占一行、写在每行代码的下面**（不是跟在行尾），一条条说明这行为什么这么写。
  - **③ 容易出错的地方**：至少 3 条「错在哪、为什么会错、怎么避免、写代码时怎么自查」，最后点评你的代码错在第几行、怎么改。
  - 右上角还有「放大到全屏」，看不清时可以把这个答案框铺满整个屏幕，再点一次「退出全屏」还原。
  - AI 万一没按三段输出，页面会提示「这次没分好段」，并把完整原文放进下面的「原始回答」里（展开即可看、可复制）。
- **练习**：要求 AI 依据原题和你这次的错误点，出 **1～3 道**（自己选）「题型相同、数据不同」的新题。默认**先只给题目不给答案**，你做完再发回去让 AI 批改，用来巩固这类题型。
- **翻译成中文**：要求 AI 把 PTA 的报错提示翻成简单直白的中文，逐条说明「它什么意思、对应我哪里错、我该怎么改」，并把术语解释成大白话；只要求粘「应用修改」那段提示，不必填题目。

唯一决定结果好坏的是你粘的题目是否完整。建议把题干、输入格式、输出格式、样例一起粘进「题目」框。

## 「立即检查」和「二次检查」的区别

「你的代码」面板顶部也写了这段说明，这里再说一遍：

- **立即检查**：页面自带的规则 + 内置 C 解释器，**不联网、不花任何额度**，边打字边跑，只挑「常见写法错误」（漏 `&`、`%d` 配 `double` 之类）。它**不评判算法与逻辑是否正确**。
- **二次检查**：拿你在「答案与解析」里生成的那份答案当**标准**，用**你自己的 AI** 把「你的代码」重新逐行对照检查一遍，结果**覆盖右侧「检查结果」**。它能发现逻辑层面的问题，但要花钱（你自己 API 的额度）、要联网。

用「二次检查」有两个前提：① 右边「题目」框里填了题；② 已经生成过答案（或把你自己 AI 给的答案粘进右边「答案与解析」框）。**每改一次代码，都要再点一次「二次检查」**才会用新代码重查；想回到本地静态检查，点一下「立即检查」即可。

## 配色与可读性

整体配色还是灰粉 / 藕粉色系：页面底色是藕粉，面板是接近白的淡粉，正文用深梅灰（在面板上的对比度约 15:1），次要文字比过去深一档（约 6:1），主色也从蓝色换成同色系的深玫红，白字在按钮上仍有 4.5:1 以上。行号、占位符、说明文字这些原来偏浅的地方都一起加深了，目的就是好看的同时真的看得清。集成测试里加了对比度断言，以后改样式不会把可读性悄悄改回去。

## 本地预览

本工具是纯静态站点，不需要构建就能打开。但因为页面通过 `<script>` 加载本地文件，建议用一个静态服务器打开（直接双击 `index.html` 也能用，个别浏览器会限制本地文件加载）。

```bash
# 方式一：内置的零依赖静态服务器（推荐）
npm run serve
# 然后浏览器打开 http://localhost:5173

# 方式二：任意静态服务器
npx serve .
```

## 检查规则清单

静态检查共 12 类规则。分三个级别：**错误**（几乎一定编译/运行失败）、**可疑**（很可能是 bug）、**建议**（写法不规范）。

| # | 规则 | 级别 | 说明 |
|---|------|------|------|
| 1 | 中文全角标点 | 错误 | 从 Word/PPT 复制代码会带上全角标点，编译器直接报错 |
| 2 | 数组越界访问 | 错误 | 只报**常量整数下标**越界，例如 `int a[5]; a[5]` |
| 3 | if/for/while 后面多写分号 | 可疑 | 分号让语句体变空，后面的代码无条件执行 |
| 4 | 条件里把 `==` 写成 `=` | 可疑 | 赋值导致条件恒真/恒假 |
| 5 | printf/scanf 占位符与参数不匹配 | 错误 | 占位符个数、类型与实参对应检查 |
| 6 | 两个整数相除被截断 | 可疑 | 仅当结果赋给**浮点变量**时才提示 |
| 7 | `while (scanf(...))` 恒真 | 可疑 | 读完数据不退出，应判断 `!= EOF` |
| 8 | 缺少头文件 | 错误/建议 | 用了 printf/scanf、字符串、数学函数却没 include |
| 9 | main 函数检查 | 错误/建议 | 缺 main、`void main`、缺 `return 0;` |
| 10 | 变量声明了却从未赋值 | 可疑 | 值随机，输出不可预测 |
| 11 | 浮点数直接用 `==` 比较 | 可疑 | 仅当确认两边是浮点类型时才报 |
| 12 | `%` 用在浮点数上 | 错误 | 取余只能用于整数 |

### 为什么规则这么少

覆盖面越大，误报越多，学生越会被误导。所以规则遵循**宁缺毋滥**：

- 数组越界**只报常量整数下标**，循环变量下标不报（静态判断不可靠）。
- 整数除法**只在结果赋给浮点变量**时提示（此时几乎一定是 bug）。
- 浮点 `==` **只在两边都确认是浮点类型**时提示。
- **刻意不做自动改写**：只告诉学生哪里不对、可以怎么改，不直接替他改代码，避免「改错」。
- 同一问题只由一条规则报出，避免同一个 bug 刷屏。

## 运行引擎

运行使用的是 [JSCPP](https://github.com/felixhao28/JSCPP)（用 JavaScript 实现的 C 语言解释器），已针对基础题场景打补丁修复了若干原生缺陷：

- `scanf` 读数组元素 / `%c` / `%lf` 报 "Memory overflow"。
- 指针写入位置错误（按数组 position 写入）。
- `EOF` 未定义、`long long` / `%lld` 输出异常。
- `scanf` 返回值语义（返回成功读入个数，EOF 返回 -1）。
- 空参数列表 `int main(void)` / `void f(void)` 被当成 "missing declarator for argument"。
- 解析器用 `eval` 解码 C 字符串转义，撞上本页面的严格 CSP（`script-src 'self'`）直接失败——已换成不依赖 `eval` 的等价实现，CSP 不用放宽。

补丁源码在 `tools/patch/` 与 `tools/shim/`，打包脚本 `tools/build-jscpp.mjs`。产物 `assets/vendor/jscpp.js` 由脚本生成、带署名 banner，并在构建时自动列出打包进去的第三方包；完整清单与许可全文见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。遇到解释器不支持的写法，页面会明确说「无法运行」，不会给假结论。

### 重建引擎

只有在改动 `tools/patch/` 或 `tools/shim/` 时才需要重建：

```bash
npm install            # 首次需要，安装 JSCPP、xterm.js 与 esbuild
npm run build:engine   # 重新生成 assets/vendor/jscpp.js（C 解释器）
npm run build:terminal # 重新生成 assets/vendor/xterm.js 与 xterm.css（终端）
npm run build:vendor   # 上面两个一起跑
```

构建产物已提交到仓库，普通使用无需重新构建。

## 安全说明

- 页面用一条严格的 **Content-Security-Policy** 锁住自己：不执行内联脚本、不加载站外脚本、不允许被别人用 `iframe` 嵌进去（防点击劫持）。第三方 API 只在你填了地址并点「在本站生成」时才会被直连。
- 没有账号系统，页面不收集任何个人信息；你的代码、题目、批改提示都只留在浏览器里。生成的答案、练习题也只在页面上，除非你自己复制到别处。
- API Key 默认不落盘：只有你主动勾「记住密钥」才写进本机 `localStorage`（键名 `pta-ai-key`）。想彻底清掉，点「API」模块里的**「清除本机保存的密钥」**按钮即可（同时清掉 `pta-ai-config`）。
- 建议在服务商后台给 Key 设置**用量上限 / 余额上限**，万一泄露损失可控；不要把这个 Key 提交进任何仓库。

## 能力边界

- 静态检查只覆盖「常见写法错误」，**不评判算法与逻辑是否正确**——逻辑要靠运行样例验证。
- 解释器覆盖基础题常用语法和标准库，少数高级特性（如复杂指针、结构体嵌套、部分库函数）可能不支持，届时会明确提示无法运行。
- 结果仅供参考，**最终以 PTA 判题为准**。
